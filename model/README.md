## Reading order

1. Read the operational model to understand the distinctions.
2. Use the inventory to check whether any required capability or resource is missing or conflated.
3. Use the evaluation matrix to compare candidate compositions without assuming that fewer or more profiles is inherently better.

## Guardrails

- These are provisional analytical artifacts, not claims that the example stack was deployed.
- Capability identity does not imply a separate profile.
- Profile/context separation does not imply execution isolation.
- Do not turn role labels into mandatory profiles without evidence.
- Do not treat source-era versions, MCP availability, or integration claims as current without verification.
- Keep unresolved choices visible until a test or explicit design decision resolves them.
